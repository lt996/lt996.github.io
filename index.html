How I design

I start from the experience a feature has to deliver (calm, presence, fairness, coordination) and work backwards to the rules that make it happen.

What I own

Features end to end: core rules, system structure, UX flows, and specs with acceptance criteria. I hand them to engineering and check the build against the spec before launch.

How I validate

I check the build against the spec before launch. After launch, I read what players say in the community to see whether they noticed what the system was designed to deliver.

In every project I ask the same question: what should the player experience, and which rule makes sure it happens?
